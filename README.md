# Concurso Transpetro — App de Estudos (Cesgranrio)

Página de estudos interativa para o Processo Seletivo **Transpetro/PSP/Terra — Nível Superior 2026.4** (banca Cesgranrio), com foco em dois cargos:

- **Administração — Ênfase 1**
- **Psicologia — Ênfase 31**

Inclui também as disciplinas comuns **Língua Portuguesa** e **Língua Inglesa**.

## Dois perfis independentes

Na abertura você escolhe quem vai estudar — **Danielle (Administração)** ou **Mariana (Psicologia)**. Cada pessoa tem a sua própria base, incluindo Português e Inglês contados separadamente; o progresso de uma nunca se mistura com o da outra. O progresso das duas fica gravado no navegador e pode ser exportado/importado por código (aba de dados).

## Funcionalidades

- **Simulados no estilo Cesgranrio** que percorrem todo o conteúdo programático.
- **Correção ao final** com gabarito comentado e, em cada questão errada, o **conteúdo para estudar** (o que revisar naquele tema).
- **Painel de evolução** por tema: mostra o que você já domina, o que está consolidando e o que precisa ampliar.
- **Rotina de estudos**: contagem regressiva para a prova (06/12/2026), meta diária, sequência de dias (streak) e plano semanal sugerido.
- **Caderno de erros** para refazer só as questões que você errou.
- Progresso salvo no navegador, com backup por código (exportar/importar).

## Como publicar no GitHub Pages

1. Suba o `index.html` (e este `README.md`) para o repositório.
2. No GitHub, vá em **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`.
4. Salve. Em alguns minutos o app estará disponível em `https://vilardani.github.io/concursotranspreto/`.

## Observações

- As questões são **autorais**, redigidas no estilo da banca para treino. Confira sempre o conteúdo programático oficial do edital.
- O app é um único arquivo `index.html`, sem dependências externas além das fontes do Google Fonts.
